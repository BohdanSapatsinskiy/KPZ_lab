# Опис проєкту

<details>
  <summary><h2>1. Фабричний метод</h2></summary>

### Основні компоненти
#### Абстрактний клас `Subscription`
Містить загальні властивості для опису підписок.

#### Конкретні класи підписок
Реалізують різні типи підписок з унікальними параметрами:
- `DomesticSubscription` – базовий пакет каналів.
- `EducationalSubscription` – навчальні та документальні канали.
- `PremiumSubscription` – максимальний набір HD-каналів.

#### Абстрактний клас `SubscriptionFabric`
Містить метод `CreateSubscription()` для створення підписки.

#### Конкретні фабрики
Реалізують створення підписок різними способами:
- `WebSite` – створення через вебсайт.
- `MobileApp` – створення через мобільний додаток.
- `ManagerCall` – оформлення через дзвінок менеджера.
</details>

<details>
  <summary><h2>2. Абстрактна фабрика</h2></summary>

### Основні компоненти

#### Абстрактний клас `Devices`
Описує загальні властивості пристроїв, включаючи бренд і тип.

#### Конкретні класи пристроїв
Реалізують різні види електронних пристроїв:
- `Laptop` – ноутбуки.
- `Smartphone` – смартфони.
- `Tablet` – планшети.

#### Інтерфейс `IDeviceFactory`
Містить методи для створення різних пристроїв (`CreateLaptop()`, `CreateSmartphone()`, `CreateTablet()`).

#### Конкретні фабрики
Реалізують виробництво пристроїв різних брендів:
- `IProneFactory` – створює пристрої бренду "IProne".
- `KiaomiFactory` – створює пристрої бренду "Kiaomi".
- `BalaxyFactory` – створює пристрої бренду "Balaxy".

</details>

<details>
  <summary><h2>3. Одинак</h2></summary>

### Основні компоненти

#### Клас `Authenticator`
Реалізує патерн **Одинак**, який гарантує існування лише одного екземпляра класу.

### Основні особливості:
- **Закритий конструктор**  
  - Запобігає створенню екземплярів ззовні.
- **Приватне статичне поле `instance`**  
  - Зберігає єдиний екземпляр класу.
- **Об'єкт `lockObj`**  
  - Забезпечує потокобезпечність при створенні екземпляра.
- **Властивість `Instance`**  
  - Реалізує ліниву ініціалізацію (`Lazy Initialization`).
  - Використовує `lock` для забезпечення безпеки в багатопотоковому середовищі.

#### Метод `Authenticate()`
Виводить повідомлення про успішну автентифікацію.
</details>

<details>
  <summary><h2>4. Прототип</h2></summary>
  
### Основні компоненти

#### Клас `Virus`
Реалізує патерн **Прототип**, дозволяючи створювати копії об'єктів.

### Основні особливості:
- **Властивості:**  
  - `Name` – ім'я вірусу.  
  - `Age` – вік.  
  - `Weight` – вага.  
  - `Type` – тип вірусу.  
  - `Children` – список дочірніх вірусів.  
- **Конструктор**  
  - Ініціалізує всі поля та створює список дітей.  

#### Метод `Clone()`
- Реалізує **поверхневе** та **глибоке копіювання**.  
- Використовує `MemberwiseClone()` для швидкого копіювання базових типів.  
- Окремо копіює список `Children`, щоб уникнути спільного використання посилань.  

#### Метод `DisplayInfo()`
- Виводить інформацію про вірус у вигляді **ієрархічної структури**.

</details>

<details>
  <summary><h2>5. Будівельник</h2></summary>

### Основні компоненти:

#### **Інтерфейс `ICharacterBuilder`**
- Декларує **ланцюговий підхід** для встановлення параметрів персонажа.  
- Всі методи повертають `this`, що дозволяє викликати їх послідовно.  

#### **Клас `CharacterAttributes`**
- Містить атрибути: `Height`, `Strength`, `Agility`, `Stealth`, `MagicPower`.  

#### **Клас `Character`**
- Основна модель персонажа.  
- Містить інформацію про ім'я, тип, релігію, зброю, броню, інвентар та атрибути.  
- Метод `DisplayInfo()` виводить всі параметри.

### **Реалізація будівельників**
#### **Клас `HeroBuilder`**
- Створює **персонажа-героя**.  
- Реалізує всі методи інтерфейсу.  

#### **Клас `EnemyBuilder`**
- Аналогічний `HeroBuilder`, але для **ворогів**.  

### **Клас `CharacterDirector`**
- Створює **типові персонажі** через `HeroBuilder` та `EnemyBuilder`.  
- Визначає шаблонні конфігурації:  
  - `CreateHero()` – **Герой: Ловчий Ночі**  
  - `CreateEnemy()` – **Ворог: Драконячий Маг**  

</details>
